## 7. Leakage Prevention

Every feature pipeline is guarded by 8 automated tests (`tests/test_ml_leakage.py`):

1. Target uses the exact T+H horizon
2. Censoring drops rows without future data
3. Velocity uses lagged rows only (no `shift(-k)`)
4. Injecting fake future values does not change past features
5. Feature columns are deterministic
6. Unseen categories are handled gracefully
7. Pipeline is bit-for-bit deterministic
8. Target builder handles missing months

Run with: `pytest tests/test_ml_leakage.py -v`
